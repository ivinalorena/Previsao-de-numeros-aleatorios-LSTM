Método do Early Stopping (RECOMENDADO)
python
from keras.callbacks import EarlyStopping

early_stopping = EarlyStopping(
    monitor='val_loss',    # Monitora loss de validação
    patience=10,           # Aguarda 10 epochs sem melhoria
    restore_best_weights=True  # Restaura melhores pesos
)

history = model.fit(
    X_train, y_train,
    validation_split=0.2,
    epochs=100,            # Número máximo (não será usado todo)
    callbacks=[early_stopping]
)

Regras Práticas para Epochs:
text
1. Dados pequenos (<1000 amostras): 50-200 epochs máximo
2. Dados médios (1000-10.000): 100-500 epochs máximo  
3. Dados grandes (>10.000): 200-1000 epochs máximo
